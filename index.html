COMPARISON · MEMORY · 12 MIN

生活记忆，
怎样抵达下一步？

对照一篇产品长文，也辨认本机 Agent 的起点。

Today AI 的博客把 Agent 放回生活连续性里讲：记忆连接偏好、项目与目标，主动性从时间和上下文中长出来，执行再回到可读的结果。文章不是一排功能卡片，而是沿着一个问题逐层展开。

本机，是另一种叙事起点

METIS 的问题更贴近桌面：一个承诺是否还没收尾？当前 Edge 页面是不是本人正在使用的工作区？一次文件操作有没有留下结果？这些关系不能从“记住更多”自动推出，而要依赖明确来源、授权范围与动作后的回读。

借用 Today 的编辑节奏，不借它的云端假设。关于记忆的叙述，应该能指回一段观察；关于行动的叙述，应该能指回一次实际结果。

METIS / 札记一 · 更新于 2026 年 11 月

PROTOCOL · COOPERATION · 9 MIN

提问是接力，
不是暂停。

后台缺少信息时，前台听见问题；回答之后，原任务继续。

后台 Agent 问问题，不应把一项工作丢进静默等待。问题要带着任务身份回到前台，语音与界面使用同一条问题记录；回答再按问题 ID 和任务代际送回去。

保持同一件事

继续、改向与取消是不同的动作。继续时，回答进入原任务，执行从等待位置接上；改向或取消时，旧任务代际失效，迟到的回答不能落到新工作里。

因此，状态图会包含“正在执行”“等待回答”“已恢复”和“已交付”。问题被生成不等于你听见了它，任务完成也不等于结果已经送达。

METIS / 札记二 · 任务协作协议

EVIDENCE · DELIVERY · 11 MIN

完成，需要两种证据：
结果与抵达。

工具回执只能说明动作发生；交付还要说明人是否收到。

研究文档可以存在磁盘上，但用户可能正在对话、听着语音，或暂时离开屏幕。我们把结果本身与结果送达分开：产物写入、短摘要生成、进入播报队列、真正播放、用户回应，分别记录。

让数字有边界

截至 2026 年 11 月 25 日，阶段二离线回归记录为 361 项、360 项通过、1 项因 Windows 权限分支跳过。它描述的是离线测试范围，不是任何真实账号、物理音箱或每个 Windows 应用都已验证。

受控网页能验证浏览器链路；真实账号仍需单独确认。测试报告保留未覆盖的部分，避免把“工具返回成功”写成“用户已经收到”。
