# METIS

An independent release site for CompanionAgent.

METIS is named after the ancient Greek figure of wise counsel: not intelligence as volume, but intelligence as the choice of the right action in a changing moment.

This site is intentionally quiet. It treats the project as an evolving relationship rather than a product pitch, and keeps experimental evidence separate from aspiration.

## Local preview

python -m http.server 4174 --bind 127.0.0.1

## Evidence boundary

The published test notes distinguish offline regression, live service chains, controlled browser tests, real-account tests, and physical playback. A controlled result is never presented as a real-account success.
